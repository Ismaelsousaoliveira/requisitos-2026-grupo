# GAC — Gerenciamento de Locação de Projetores

Sistema para automatizar e otimizar o processo de locação e devolução de projetores multimídia no Centro de Ciências Tecnológicas (CCT).

## 🏛️ Sobre o Projeto

**Disciplina:** Requisitos de Software  
**Professor:** Marcelo Bezerra  
**Grupo:** Grupo 2 — Equipe Dois  
**Período:** 2026.1

## 📋 Entregas

### P1 — Visão e Elicitação (MVP)
- Documento de visão e demanda
- Backlog do produto (6 US)
- Requisitos funcionais (7 RF)
- Requisitos não funcionais (6 RNF)
- Regras de negócio (7 RN)
- Diagramas UML (casos de uso, classes, sequência)

### P2 — SRS e Prototipação ✅
- **SRS (IEEE 830):** Especificação completa de requisitos de software
- **Revisão de consistência:** Alinhamento UML × requisitos
- **Protótipos navegáveis:** 13 telas em HTML interativo
- **Issues:** Planejamento organizado por sprints
