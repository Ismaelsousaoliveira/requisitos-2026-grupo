# Plano de Sprints — P2

## Milestone M2 (Sprints 4 e 5)

### Convenção de Issues

Cada issue no GitHub segue o formato:

```
[USXX] Título da História — Tarefa específica
```

**Labels utilizadas:**
- `sprint-4` — Issues da Sprint 4
- `sprint-5` — Issues da Sprint 5
- `usXX` — Referência à história de usuário
- `rfXX` — Referência ao requisito funcional
- `bug` — Correção
- `documentation` — Documentação
- `enhancement` — Melhoria
